# Contributing

1. Read [`ARCHITECTURE.md`](ARCHITECTURE.md). A change must keep the invariants.
2. Open an issue before a large change.
3. Start with a test. `tests/conftest.py` has the fixtures.
4. Run `inv ci`. It must pass.
5. Use no real case data in a test, an issue, or a pull request.

Code names are English. Names on disk and text for the user are Dutch;
[`CLAUDE.md`](CLAUDE.md) lists the terms.

Your contribution gets the licence of the project: AGPL-3.0-or-later.
